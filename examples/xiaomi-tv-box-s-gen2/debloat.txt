# Xiaomi TV Box S (2nd Gen), model MiTV-AFKR0, Google TV, Android 14, Amlogic S905X4, 2 GB RAM
# Apply: tools/windows/debloat.ps1 examples/xiaomi-tv-box-s-gen2/debloat.txt   Undo: tools/windows/restore.ps1 <same file>
# Everything is DISABLED for user 0, never uninstalled. A factory reset re-enables it all.
#
# Before disabling the ambient screensaver, point the screensaver at Android's own:
#   adb shell settings put secure screensaver_components com.android.dreams.basic/.Colors
# The stock launcher (launcherx) and Google's setup app (setupwraith) are handled when the
# launcher is installed, not here; see the README.
#
# Left alone on purpose: mitv.service, xiaomi.tvservice, com.xiaomi.mitv.updateservice
# (firmware security updates), Play Store, Play Services, the keyboard, Wi-Fi and HDMI services.
